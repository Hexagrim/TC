# The Cabin

---

It's a game about escaping a house while being hunted by a scary monster.

<p align="center"><i>(very original idea**)</i></p>

The player gets **1 life** to find, explore and solve all the puzzles to escape the house before the monster eats them and their speaker.

## Controls

| Key | Action |
|:---:|:---|
| `WASD` | MOVE |
| `F` | interact |
| `E` | pick and throw |
| `LMB` | to use torch |
| `SHIFT` | toggle crouch |

## Tools used

-Unity 6
-Blender
-Photoshop 2026
-Assets from SketchFab and Itch

### This was my first proper 3d game, so bugs are expected. There is a problem with web building being that the APV(Adaptive probe volumes) are not supported whole the entire main scene depends on it. So lighing is bugged for web build.
